# 製作背景與初衷
目前，遊戲內的繁中存在了諸多問題。（例如：錯字、漏譯缺譯、UNKNOWN）其不僅破壞了遊戲體驗，還誤解了角色設定，以及被埋沒的世界觀設定與伏筆。雖已有社群製作優化補丁，但多是基於自帶簡中進行的二次轉換，導致部分原簡中的錯誤翻譯被保留了下來。基於此現狀，我決定著手修正繁體中文，來解決現存問題。

# 錯誤發現與回饋
本補丁可能存在潛在的錯誤。若各位主管在遊戲過程中遇到字型過小、排版重疊或異常、漏譯、錯別字或語詞不當，歡迎積極反饋。我會認真傾聽意見並著手修復問題。但還請保持友善。
安裝步驟及還原方法
若要安裝，請在「Steam所在目錄\Steam\steamapps\common\LobotomyCorp\LobotomyCorp_Data」內點開「ExternalData」資料夾，將「xml」檔案全部取代。
若要還原，請刪除「ExternalData」資料夾，在Steam介面右鍵點選遊戲→內容→本機檔案→驗証遊戲檔案的完整性…
