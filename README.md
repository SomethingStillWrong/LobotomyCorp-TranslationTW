# 製作背景與初衷
目前，遊戲內的繁中存在了諸多[問題](#腦葉公司繁中問題一覽)。（例如：錯字、漏譯缺譯、UNKNOWN）其不僅破壞了遊戲體驗，還誤解了角色設定，以及被埋沒的世界觀設定與伏筆。雖已有社群製作優化補丁，但多是基於自帶簡中進行的二次轉換，導致部分原簡中的錯誤翻譯被保留了下來。基於此現狀，我決定著手修正繁體中文，來解決現存問題。

# 腦葉公司繁中問題一覽（✔為本補丁已修復內容）
- [x] 部分異想體編號不正確  
沉默樂團的編號在繁中是T-01-55，為Legacy時期編號。現版本為T-01-31

- [x] 部分異想體危險等級不正確  
銀河之子的危險等級變為了ZAYIN（實際為HE）、人皮啟示錄的危險等級變為了WAW（實際為TETH）

- [x] 部分異想體檔案描述未更新  
愛娜溫的韓文檔案新增了一句話，但繁中檔案未新增

- [x] 遊戲內的標點符號皆使用半形  
（雖然覺得不是問題，但半形標點符號在中文語境的可讀性會大幅下降，影響遊戲體驗）

- [x] 部分異想體管理須知漏翻譯、不正確、格式不一致    
無名怪嬰的第三條須知會讓異想體的逆卡巴拉計數器減少，這點在韓文有體現，但繁中未將其翻譯出來  
（部分管理須知未在韓文詳細寫出，為方便管理，將會根據正確描述（如Wiki）修改）<br>  
目前，遊戲內的翻譯格式很亂，以下文字節選自檔案內（差的基本一致）：   
優：  
當工作的結果為優良時, 逆卡巴拉計數器增加了.  
當工作的結果為優時, 逆卡巴拉計數器減少了.<br><br>
良：  
當工作結果為良好時, 逆卡巴拉計數器增加了.  
當工作的結果為普通時, 逆卡巴拉計數器會減少 F-02-70-5 的外觀會改變.  

- [ ] 部分異想體缺失翻譯  
目前，深黯軍團、月光女神、風雲法師、波迪、寄生樹在遊戲內都沒有翻譯

- [x] 說話者未完全翻譯
此處的說話者，是指劇情中出現的職員（Employee、Employee 1,2等），人名不翻譯不算入問題內  
（部長名稱不翻譯的原因，還請參見廢墟圖書館NS版繁中的詭異音譯。本補丁對其生前名字翻譯，是為了對照廢墟圖書館的人名處理方式）

- [ ] 翻譯品質過低  
若是開過繁中玩過，就會知道品質究竟有多低。這也是本補丁的誕生原因。根據遊戲內表現，推測是基於之前英翻（即Cool Kids Club翻譯組前的英文翻譯組）進行的翻譯。而且近乎沒有經過審核。錯字問題也是因此而生
